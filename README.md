# Cuerpia · descargas

APK de prueba de Cuerpia para Android (móviles de 64 bits).

Descarga: https://github.com/LightLeopard502/cuerpia-descargas/raw/main/cuerpia.apk

Páginas públicas (para la ficha de Google Play):
- Política de privacidad: https://lightleopard502.github.io/cuerpia-descargas/privacidad/
- Eliminar la cuenta: https://lightleopard502.github.io/cuerpia-descargas/borrar-cuenta/

La política se genera desde `lib/legal.ts` de la app: si cambia el texto allí, hay que regenerarla.
